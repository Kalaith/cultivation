# Cultivation Professions System

Professions advance in tiers that usually mirror cultivation realms.

**Common Structure:**
`Apprentice` → `Adept` → `Master` → `Grandmaster` → `Saint` → `Immortal`

**Direct Realm Mapping:**
`Mortal` → `Qi` → `Foundation` → `Core` → `Soul` → `Immortal`

---

## Core Professions (with Realm Scaling)

| Realm Tier | Title | Can Create |
| :--- | :--- | :--- |
| **Mortal** | Herbalist | Healing salves |
| **Qi Condensation** | Pill Apprentice | Qi recovery pills |
| **Foundation** | Pill Adept | Breakthrough aids |
| **Golden Core** | Pill Master | Core-stabilizing pills |
| **Nascent Soul** | Pill Grandmaster | Soul-healing pills |
| **Immortal** | Immortal Alchemist | Law pills, rebirth pills |

**Gameplay Perks:**
*   Higher realm = higher pill tier unlocked
*   Failure chance decreases with mastery
*   Can assist tribulations
*   Can bypass cultivation bottlenecks

## Rules Common in Stories

### 1. Realm Limits Skill Ceiling
> A Qi cultivator cannot refine a Nascent Soul pill even with knowledge.

### 2. Professions Require Special Stats
*   **Alchemist** → Spirit Sense, Control
*   **Healer** → Soul Power, Precision
*   **Artificer** → Strength + Qi Control

### 3. Dual Cultivators Are Rare
Combat + Profession slows realm growth but gives massive utility.

### 4. High Realm Professionals = Strategic Assets
Wars are often won by alchemists, not swords.

### Example: Game Integration Table
| Profession | Primary Stat | Realm Gate | Output |
