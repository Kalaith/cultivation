# Project Review

## Project

**Name:** Heavenly Mandate

**One Sentence Pitch:** raise a sect from the ruins


# 1. First Impression
Spend 10-20 minutes using the project without making changes.
- ui could use some improvement, the beige makes it a little hard to read
- the log shows code text and not swapped out correctly to ingame text
- the tutorial is there but maybe it could highlight where to go next
- viewing a disiple it was visible what the bottleneck is, the player shouldn't see this without the right unlocks/buildings/training
- the story feels hidden, a visual novel style intro with the patriach finding his destroyed sect and vowing to rebuild it.


# 2. Story
Would I keep reading?
- goal should be to live out a progression fantasy, with the sect getting powerful, most of the story should be emergent gameplay from disiciples, breaking bottlenecks, doing impossible quests, enemies attacking.

# 3. Does it Have Potential?
Ignoring its current state...
Could this become something great with more work?
- it does have the potential to be a really good idle game

# 4. Biggest Problems
- UI is very vague and hard to read, some overlapping elements

# 5. Best Parts
What already works well?
- building up a sect via repairs
- getting disiples and sending them on missions


# 6. Next Goal
What is the **single most important milestone**?
- A good intro game to give the player a reason to be interested in playing.

# 7. Content Notes (Optional)
Would this make an interesting YouTube video or livestream?
could make a good idle video, with the sect growing strong over time.
